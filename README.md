# Lampstand

Offline, web-based church presentation app: AI-prepared sermon slides on a projector, with instant Bible verse lookup that never interrupts the slides.

See [docs/PRD.md](docs/PRD.md) for the full product spec and [docs/DECISIONS.md](docs/DECISIONS.md) for choices made during the build.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173
npm run ci         # lint, type check, unit tests, build, Playwright
```
