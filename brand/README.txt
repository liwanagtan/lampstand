LAMPSTAND — LOGO KIT
====================

Mark: a flame rising from an open book ("Thy word is a lamp unto my feet", Psalm 119:105).
Wordmark: "lampstand" in Plus Jakarta Sans ExtraBold, tracking -4%, converted to outlines
(no font install needed).

Every logo comes as SVG (scalable, use this whenever possible) and PNG (transparent background).


FOLDERS
-------
mark/                The symbol alone. Use where the name already appears nearby.
lockup-horizontal/   Mark + wordmark side by side. The default logo.
lockup-stacked/      Mark above wordmark. For square spaces, splash and logo screens.
wordmark/            The name alone. For tight horizontal spaces.
app-icon/            Icons for the app, browser and home screens.


COLOR VARIANTS
--------------
color-on-light   Gold flame, ink book and text. For light backgrounds.
color-on-dark    Gold flame, cream book and text. For dark backgrounds.
mono-ink         All ink. For one-color printing on light backgrounds.
mono-white       All white. For photos, video and one-color use on dark backgrounds.


APP ICONS
---------
lampstand-icon-rounded       Rounded tile. Web, desktop shortcut, PWA "any" icon. 1024–64 px.
lampstand-icon-square        Full-bleed square for iOS / app stores (the system rounds corners). 1024, 180 px.
lampstand-icon-maskable      Extra padding for Android / PWA maskable icons. 512, 192 px.
lampstand-icon-small         Heavier shapes that stay clear at tiny sizes. 48, 32, 16 px.
favicon.ico                  16, 32 and 48 px in one file, for the browser tab.

Web app manifest example:
  { "src": "lampstand-icon-rounded-512.png",  "sizes": "512x512", "type": "image/png", "purpose": "any" }
  { "src": "lampstand-icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  { "src": "lampstand-icon-maskable-192.png", "sizes": "192x192", "type": "image/png", "purpose": "maskable" }


BRAND COLORS
------------
Ink      #0A0F1C   Primary dark, text and backgrounds
Cream    #F5F2EA   Primary light
Gold     #F2B33D   The flame. Accent only, never for body text on light backgrounds
White    #FFFFFF   Mono use only


USAGE
-----
- Clear space around the logo: at least the height of the flame on every side.
- Minimum size: horizontal lockup 120 px wide on screen; mark 24 px (use the small icon below 32 px).
- Don't stretch, rotate, recolor outside these variants, add effects, or put the color logo on busy photos
  (use mono-white with a dark overlay instead).
