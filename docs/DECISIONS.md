# Decisions

Dated choices not covered by the PRD (docs/PRD.md §14).

- 2026-10-16 — Package manager: npm (pnpm not installed on the dev machine).
- 2026-10-16 — Styling: CSS Modules + CSS variables, not Tailwind. `src/design-system/tokens.ts` is the single source of truth and injects all tokens as CSS variables at startup (`applyTokens`).
- 2026-10-16 — Fonts: `@fontsource-variable/inter` and `@fontsource-variable/fraunces` (OFL), bundled by Vite so nothing is fetched at runtime.
- 2026-10-16 — Versions: React 19, React Router 7, Vite 8, Zod 4, Dexie 4, TypeScript 5.9 (TS 7 skipped until typescript-eslint supports it), ESLint 9.
- 2026-10-16 — Contrast fixes to PRD tokens (contrast test failed on PRD values): light `success` #1F9D5A → #1C9455 (was 2.98:1 on surface-raised); text on the light accent fill and on the dark live fill uses near-black (`accent-contrast`, `live-contrast`) because white measured 4.03:1 and 3.91:1.
- 2026-10-16 — Accent, live, success and warning are UI colors (≥ 3:1). Body text always uses `text` or `text-muted` (≥ 4.5:1 on all surfaces).
- 2026-10-16 — "Control screen defaults to Dark": the Present screen resolves the System appearance to Dark; an explicit Light choice is respected.
- 2026-10-16 — Default app appearance is System.
- 2026-10-16 — Canonical book codes are the three-letter USFM/Paratext codes the PRD uses (JHN, PSA, 1CO). `src/features/bible/books.ts` maps them to the parser's OSIS names (John, Ps, 1Cor).
- 2026-10-16 — Translation codes in the command bar ("jn 3 16 web") are peeled off before parsing, because the reference parser only knows a few codes (ASV, KJV). "darby" is accepted as an alias for DBY.
- 2026-10-16 — Stored presentations keep the human `ref`; the canonical range is computed with `parseRef` when needed (memoised), so exported files stay valid against the strict schema.
- 2026-10-16 — "≤ 6 verses per slide" is a warning on import, not an error, since the renderer paginates long passages (PRD §5 says passages are never truncated).
- 2026-10-16 — A reference with several passages ("John 3:16, 18") is rejected for verse slides; one passage per slide.
- 2026-10-16 — Field limits not given in the PRD: title ≤ 80, speaker/series ≤ 60, notes ≤ 2000, image description ≤ 200, quote author ≤ 60, countdown label ≤ 40, list heading ≤ 60, up to 6 emphasis phrases, up to 40 extraRefs.
- 2026-10-16 — Import accepts JSON wrapped in a ```json code fence, since that is how the skill outputs it.
- 2026-10-16 — Bible sources: KJV, ASV, YLT and Darby from scrollmapper/bible_databases (formats/json); WEB from eBible.org (engwebp, Protestant canon) because scrollmapper has no WEB. All five are public domain; the license is recorded in each file.
- 2026-10-16 — WEB text is bundled unmodified: its license asks that changed text not be called the World English Bible. Other translations get typographic cleanup only (Darby's missing space before "God" and its [ ] / * markers, YLT backtick quotes and "--", KJV italics brackets, ASV "[Selah", Psalm 119 Hebrew letter headings).
- 2026-10-16 — Verses a translation omits (e.g. ASV Matthew 17:21) are stored as empty strings and shown as "not included in this translation". WEB's Romans doxology sits at 14:24–26 rather than 16:25–27.
- 2026-10-16 — Generated public/bibles/*.json (~21 MB) is committed so the app builds and runs without network. `npm run bibles` regenerates it from scripts/.cache.
- 2026-10-16 — A bundled translation reloads only when its content hash in public/bibles/index.json changes.
- 2026-10-16 — Word search runs in a Web Worker (MiniSearch, common English stop words dropped, prefix match on the last word, light fuzziness for long words, exact phrases ranked first) so building the index never blocks the control screen. At most two translations are indexed in memory.
- 2026-10-16 — TV accent colors lightened to meet the 7:1 text contrast rule (PRD §10), because references and emphasis are accent-colored text: Modern #5B8CFF → #7FA5FF (6.26 → 8.23:1), Warm #D9774B → #E8956B (5.66 → 7.57:1). Classic gold #D9A441 already passes (8.24:1).
- 2026-10-16 — Warm template: headings in Inter 600; Fraunces 500 italic is its accent font (quotes). Classic quotes also use Fraunces italic; Modern stays all-Inter.
- 2026-10-16 — Verse text auto-fits per page between 52 px (verse size) and 40 px (minimum body size); pages are packed at 40 px, split at verse boundaries, then sentence breaks, then words. Text is measured with the template's body font on a canvas.
- 2026-10-16 — Countdown digits use a 240 px display size (not in the PRD scale) so they read from the back of the room.
- 2026-10-16 — Bundled backgrounds: 20 photos from Wikimedia Commons (CC0, public domain or CC BY — no share-alike), because Unsplash and Pexels need API keys. Credits in public/backgrounds/LICENSES.md. Images are 1920×1080 WebP (~4.9 MB total) with 384×216 thumbnails.
- 2026-10-16 — Choosing a bundled background copies it into the assets table (id `bg-<name>`), so all image backgrounds are referenced by assetId.
- 2026-10-16 — Image backgrounds without a chosen file show a labelled dashed placeholder in the editor and previews, and the template background on the TV.
- 2026-10-16 — Library: clicking a card's thumbnail presents it; Edit, Duplicate, Export JSON and Delete live in the card's menu. Sort options: sermon date, last presented, recently edited. Search also matches series.
- 2026-10-16 — Delete removes the record at once and keeps it in memory for the 8-second undo toast; undo puts it back unchanged.
- 2026-10-16 — Exported JSON keeps background assetIds; on another laptop those backgrounds show as "needs a background" placeholders.
- 2026-10-16 — Import with errors still previews every slide that parses on its own, so each error can jump to its slide; slides that can't parse show a "can't be shown" card.
- 2026-10-16 — Import limits: presentation files up to 5 MB, videos up to 400 MB (stored as-is), images resized to ≤ 1920 px wide and saved as WebP (quality 0.82).
- 2026-10-16 — Slide drawings are aria-hidden; each frame carries its own label, so page headings stay meaningful for screen readers.
- 2026-10-16 — Each live snapshot carries the whole presentation (a few KB), so the output can draw the TV with no other input and keeps the last image if the control window dies. The output reads verse text and images straight from IndexedDB.
- 2026-10-16 — With Window Management permission the output opens as a fullscreen popup (`popup,fullscreen` window features) on the non-primary screen. Without it, a normal popup shows a "Drag this window to the TV and press F" hint, which disappears in full screen.
- 2026-10-16 — Output connection: the output says hello on load, sends a heartbeat every 1.5 s and bye on close; the control marks it disconnected after 4 s of silence.
- 2026-10-16 — Preview follows the slide after the live one until the operator picks a thumbnail; Enter or "Go live" sends the preview. Double-clicking a thumbnail sends it live directly.
- 2026-10-16 — Next walks through build items, then through the pages of a long verse slide, then to the next slide. Previous steps back the same way, and entering a slide backwards shows it fully built on its last page. ↑/↓ and Home are extra aliases.
- 2026-10-16 — Live state is mirrored to sessionStorage so a reloaded control window resumes where it was.
- 2026-10-16 — Content already live when an output (re)opens is drawn in its final state, without replaying entrance motion; anything sent afterwards animates normally.
- 2026-10-16 — The countdown starts when its slide goes live and keeps running if the operator re-enters the same slide.
- 2026-10-16 — The default logo screen shows the Lampstand mark until a logo image is set in Settings.
- 2026-10-16 — Command bar: Enter shows a typed reference live; Shift+Enter loads it into Preview; Ctrl/Cmd+Enter adds it to the queue. Word-search results (quoted text, or text that isn't a reference) load into Preview on Enter, as the PRD says, so a search hit never reaches the TV without a second Enter.
- 2026-10-16 — After a verse goes live the command bar closes, so the next Esc clears the overlay. Esc inside the bar first clears its text, then closes it.
- 2026-10-16 — The translation chip in the control screen sets the session's verse translation (default: the presentation's). T on a live verse cycles through installed translations in order (KJV, WEB, ASV, YLT, DBY, then imports).
- 2026-10-16 — Next/previous verse (Alt+→/←) first pages through a long passage, then steps to the single verse after the passage's end, or before its start, crossing chapters and books.
- 2026-10-16 — Overlay mode keys 1/2/3 also set the mode for the next verse in this session; the default comes from Settings.
- 2026-10-16 — Verse history keeps this session's list in memory and writes every shown verse to the Dexie history table, capped at 200 entries.
- 2026-10-16 — Ctrl+K palette commands: verse, overlay modes, next/previous, blank, logo, open output, shortcut sheet, back to library, and "go to slide N".
- 2026-10-16 — Editor: typing in one field within 0.8 s counts as a single undo step; undo/redo keep 50 steps each. Autosave runs 0.4 s after the last edit; "Saved" shows for 1.5 s. Ctrl+Z / Ctrl+Shift+Z (and Ctrl+Y) work even while a field has focus.
- 2026-10-16 — Edits may leave a slide temporarily invalid (empty heading, text over its limit, unknown reference). It is saved anyway, so nothing is lost; the slide gets a warning badge in the strip and its problems are listed above its fields.
- 2026-10-16 — Changing slide type is offered only when every piece of content has a place in the new type and fits its limits (point ↔ closing ↔ title, section → title/point/closing, quote ↔ statement). Nothing is ever silently dropped.
- 2026-10-16 — Reordering: drag by the grip in the slide list, or use Move up/down. A presentation always keeps at least one slide.
- 2026-10-16 — Backup file = presentations, settings and every stored asset (base64) in one JSON file, built as streamed Blob parts. Restore merges by id, keeps whichever copy was edited last, and never deletes.
- 2026-10-16 — Settings → About credits the Bible sources, background photographers, fonts and icons.
- 2026-10-16 — The operator's Reduce motion setting travels in the live snapshot, so an open output window follows it at once.
- 2026-10-16 — Menus label their popup content rather than their trigger, so a button keeps its visible text as its accessible name.
- 2026-10-16 — Library thumbnails show the first slide that isn't a countdown, so cards are recognisable (most sermons open with a countdown).
- 2026-10-16 — PWA: vite-plugin-pwa in "prompt" mode precaches the app shell, fonts, icons, Bible data and backgrounds (~27 MB). An update never applies itself; outside the control and output screens a toast offers "Restart".
- 2026-10-16 — Errors: each feature area (command bar, side panel, slide strip, panes, editor fields, verse overlay, output) has its own error boundary. On the TV a failure renders nothing rather than an error message.
- 2026-10-16 — Shortcut hints appear beside Next, Previous, Blank, Logo and Go live when clicked with the mouse, for the first five uses of each (counts stored in settings).
- 2026-10-16 — Going live shows a short accent outline flying from the Preview pane to the Live pane (standard motion token), plus the one-time LIVE border pulse.
- 2026-10-16 — Accessibility is checked with axe-core in Playwright (WCAG 2.2 AA, light and dark); slide drawings are excluded there because their 7:1 TV contrast is unit-tested.
- 2026-10-16 — Performance targets (§10) are measured in Playwright: cold start, verse lookup and go-live latency. The soak test (`npm run soak`) defaults to 2 hours and checks memory growth ≤ 10% and < 600 MB.
- 2026-10-16 — Bundle: the main chunk is ~715 KB (215 KB gzip), mostly the reference parser's English data and UI libraries. Everything is precached and read from disk, and measured cold start is well under the 2 s target, so it stays one chunk; the warning limit is raised to 800 KB.
- 2026-10-16 — Thumbnail buttons (library cards, editor list, control strip) sit over the slide drawing and carry only a hidden text label, so their accessible name matches their content (WCAG 2.5.3).
- 2026-10-16 — Tab panels stay mounted (inactive ones hidden), and the command bar keeps an empty hidden listbox while closed, so `aria-controls` always points at a real element.
- 2026-10-16 — 6-minute soak run on the dev machine: 302 steps of slides, verses and overlay changes; heap ~15–16 MB per window, 8.5% growth, mostly warm-up. The verse history and passage cache are capped at 200 entries, so growth is bounded over 2 hours. Run the full 2 hours on the church laptop with `npm run soak`.
- 2026-10-16 — UX update, phase 1: a top bar (brand, Library/Import/Settings tabs with a gold underline, appearance switch) replaces the sidebar. The Library header holds search, sort and Import on one row. Import is upload-only (drop or choose a file); the paste box is gone. The empty library uses an illustrated lamp with a gently flickering flame (static under Reduce motion) and plain copy with no mention of Claude.
